Правила профессий

🧑‍🤝‍🧑 ЖИТЕЛИ ГОРОДА (Мирные)

Общие правила: Не могут участвовать в крупных криминальных действиях (ограбление банка, война).

Исключение: Охранник может защищать банк, если его нанял Банкир.

Гражданский

  • ✅ Может нелегально иметь принтеры.
  • ✅ Может сотрудничать с криминалом и гос. служащими.

Паркурист

  • ✅ Может нелегально иметь принтеры.
  • ✅ Может сотрудничать с криминалом и гос. служащими.

Охранник

  • ✅ Может нелегально иметь принтеры.
  • ✅ Может сотрудничать с криминалом и гос. служащими.

Бармен

  • ✅ Может нелегально иметь принтеры.
  • ❌ Не может сотрудничать с криминалом и гос. служащими.
  • ❌ Нельзя ставить игровые автоматы без видимых расценок и казино вне жилых помещений.

Продавец оружия

  • ✅ Может нелегально иметь принтеры.
  • ✅ Может сотрудничать с криминалом и гос. служащими.

Владелец казино

  • ✅ Может легально хранить денежные принтеры.
  • ❌ Не может сотрудничать с криминалом.

📌 Обязан иметь вывеску и оборудованное помещение. Все игры должны быть честными (через /roll).

Врач

  • ❌ Не может рейдить, грабить, похищать.

📌 Лечит всех. Может быть подпольным врачом для криминала.

Бездомный (Бомж)

  • ❌ Не может иметь принтеры.
  • ✅ Может грабить всех игроков (кроме Предводителя и других Бездомных).
  • ❌ Не может сотрудничать с гос. служащими.

Предводитель бездомных

  • ❌ Не может иметь принтеры.
  • ✅ Может грабить всех игроков (кроме своих подчиненных).
  • ✅ Может сотрудничать с криминалом.
  • ❌ Не может сотрудничать с гос. служащими.

📌 Лидер группировки бездомных, может нанимать других Бездомных.

👑 ГОСУДАРСТВЕННАЯ ВЛАСТЬ

Мэр

  • ❌ Не может иметь принтеры (только хранение у Банкира).
  • ❌ Запрещено сотрудничать с криминалом (исключение: принуждение).

📜 Законы: Не должны призывать к постоянному расстрелу/аресту вне военного положения.

🚫 Запреты: Нельзя вводить налоги на жизнедеятельность (дышать, прыгать) и ставить цену лицензии выше 50.000.

⚔️ Война: Может объявить военное положение только в случае объявления войны.

  • ❌ Не может сотрудничать с криминалом.

📌 Обязан иметь банк с вывеской.

Инкассатор

  • ✅ Может сотрудничать с Банкиром и гос. служащими.
  • ❌ Запрещено сотрудничать с криминалом.
